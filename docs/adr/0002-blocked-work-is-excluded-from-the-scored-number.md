# Blocked work is excluded from the scored number, and a block must cite a message

RKB realisation is the only percentage in the system and feeds Rapor Pimpro A.1 at 30% weight.
The Facade sheet runs on a date-banded equipment schedule and a rain-contingency list, and the
group shows work stalling because a gondola or scaffolding never arrived. Scoring a Pimpro down
for equipment that did not show up would make the one scored number unfair, and he would
rightly reject the system.

So a blocked row is excluded from the *net* figure the Pimpro is scored on, while the client
still sees the gross. The same pause applies to the complaint SLA clock.

## Consequences

Blocking becomes the one state a supplier could use to improve its own numbers. It is therefore
invalid without a citation to the message that justifies it — enforced at the schema, not by
convention, and rejected at ingest rather than rendered with a warning.
